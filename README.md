# Web3 Analytics Dashboard

AI-powered multi-chain Web3 analytics dashboard for tracking on-chain activity, ecosystem growth, wallet intelligence, NFT trends, and real-time community engagement across major blockchain ecosystems.

---

## Overview

Web3 Analytics Dashboard is a modern Web3 analytics platform designed to help developers, researchers, traders, and communities understand blockchain ecosystem growth with transparent and reliable data.

The platform aggregates analytics from multiple blockchain networks and combines on-chain metrics with social engagement insights from platforms like Twitter/X and Discord.

Users can monitor wallet activity, discover trending projects early, analyze ecosystem performance, and receive real-time alerts.

## Installation

```bash
# Clone repository
git clone https://github.com/yourusername/web3-analytics-dashboard.git

# Navigate into project
cd web3-analytics-dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## Environment Variables

Create a `.env.local` file and add:

```env
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=
NEXT_PUBLIC_ALCHEMY_API_KEY=
DATABASE_URL=
JWT_SECRET=
SHELBY_API_KEY=
```
